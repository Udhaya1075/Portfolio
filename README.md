# Portfolio — how to update
Open index.html in a browser (or upload the folder to GitHub Pages / Netlify).
1. Put your photo at assets/profile2.png
2. Update content ONLY in the data block at the top of each js/sections/*.js file
3. Home text: edit the first section in index.html
4. Colours: css/base.css (:root)
See PROGRESS.md for the full status and CREDITS.md for credits.
